# EduTrack Atomic UI Design System

## Structure
- **Atoms**: `Button`, `Input`, `Avatar`, `Badge`, `Chip`, `Divider`, `Loader`, `Icon`.
- **Molecules**: `SearchBar`, `SectionHeader`, `PasswordInput`, `Snackbar`, `Toast`, `Dropdown`.
- **Organisms**: `Card`, `Modal`, `BottomSheet`, `DataTable`, `EmptyState`, `ErrorState`, `FAB`.
- **Templates**: `ScreenWrapper`, `ModuleShell`.

## Component Requirements
All components support:
- Light & Dark mode adaptation.
- Loading & Disabled states.
- Accessibility props (`accessibilityLabel`, `accessibilityRole`).
- NativeWind styling + variant props.
