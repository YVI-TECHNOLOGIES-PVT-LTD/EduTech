# PHASE 2.5 — ADMISSION APPLICATION MANAGEMENT REPORT
**EduTrack ERP Web Application**

---

## 1. Module Scope

The Admission Application Management module handles formal application intake, status processing, and applicant 360 views:
- **Application Intake**: Public registration, staff application creation, and lead conversion.
- **Application Tracking**: Distinct `application_number` independent from lead number.
- **Status Lifecycle**: `SUBMITTED` → `UNDER_REVIEW` → `DOCUMENTS_VERIFIED` → `ASSESSMENT_COMPLETED` → `DECISION_MADE` → `FEE_PAID` → `ENROLLED`.
- **Applicant 360 View**: Consolidated view of student details, parent details, document status, assessment scores, and timeline.
