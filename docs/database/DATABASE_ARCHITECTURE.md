## 2. Structural Principles & Policies

- **Normalization:** Strict Third Normal Form (3NF). Data redundancy eliminated (e.g. current student grade calculated via `student_enrollments`).
- **Multi-Tenant Scoping:** Primary entity tables scoped via `org_id` foreign key.
- **Audit Trail Policy:** Standard transactional tables include `created_at`, `updated_at`, `created_by`, `updated_by`.
- **Triggers:** 24 tables use `BEFORE UPDATE` triggers executing `set_updated_at()` ([`07_triggers.sql`](file:///c:/Program%20Files/EduTech/apps/database/stage_1/schema/07_triggers.sql)).
- **System Keys vs Business IDs:** Database primary keys use UUID strings. Business readable identifiers (e.g., `APP-2026-000031`, `ENQ-2026-000124`) are generated by application services.
