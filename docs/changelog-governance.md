## CHANGELOG.md Rules
1. **Single Source of Truth**: All release changes MUST be documented in root [`CHANGELOG.md`](file:///c:/Users/DELL/OneDrive/Desktop/School_Management_System/CHANGELOG.md).
2. **Standard Sections**: Group release notes into standard categories:
   - `Added` for new features or infrastructure platforms.
   - `Changed` for modifications to existing functionality.
   - `Deprecated` for features slated for removal.
   - `Removed` for deleted features or endpoints.
   - `Fixed` for bug fixes.
   - `Security` for vulnerability patches.
3. **Commit Linking**: Include PR numbers or Git commit hashes where applicable.
