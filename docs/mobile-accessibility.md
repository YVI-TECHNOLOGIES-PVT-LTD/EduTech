# EduTrack Mobile Accessibility Standard

## Accessibility Guidelines for Mobile
1. **Screen Reader Support**: All touchable elements MUST provide `accessible={true}` and `accessibilityLabel="..."`.
2. **Minimum Touch Targets**: Ensure all interactive buttons have a minimum touch target size of **44x44 dp**.
3. **Contrast Compliance**: Ensure text contrast meets WCAG AA standards in both Light and Dark themes.
