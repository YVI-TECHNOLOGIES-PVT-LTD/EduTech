## SemVer 2.0.0 Standard
All EduTrack packages (`@edutrack/api`, `@edutrack/web`, `@edutrack/mobile`, `@edutrack/config`, `@edutrack/types`, `@edutrack/validation`, `@edutrack/ui`) strictly adhere to Semantic Versioning (`MAJOR.MINOR.PATCH`):

- **MAJOR (x.0.0)**: Increment for breaking architectural changes, removed API routes, or incompatible response envelope modifications.
- **MINOR (0.x.0)**: Increment for backward-compatible feature additions, new API endpoints, or new shared UI components.
- **PATCH (0.0.x)**: Increment for backward-compatible bug fixes, security patches, or documentation updates.
