## 3. Web Frontend Architecture Inventory (`apps/web_app/src/`)

### 3.1 API Clients & State Management Fragmentation

A critical architectural finding in `apps/web_app/src/` is the **coexistence of 4 overlapping HTTP/state stacks**:

1. **RTK Query + Redux Toolkit** (`apps/web_app/src/app/store/`):
   - `apiSlice.ts` (`createApi`, 24 `tagTypes` up to `ParentPortal`, empty injected `endpoints: () => ({})`)
   - `baseQueryWithReauth.ts` (injects `Authorization` + `x-tenant-id`, handles FormData boundary, performs 401 `/auth/refresh` rotation, clears auth on failure)
   - `rootReducer.ts` (`auth`, `permission`, `ui`, `notification`, `tenant`, `parentPortal`, `api`)
   - Consumed via endpoint injectors (`apps/web_app/src/shared/api/*.api.ts`, `endpoints.ts`, `api/*.api.ts`) — **Note**: `.agents/AGENTS.md` mandates RTK Query for all new frontend API layers.
2. **Axios Client (`lib/api-client.ts`) + React Query (`@tanstack/react-query`)**:
   - Observed in `75` files using `apiClient`/`axios` and `33` files using `@tanstack/react-query` (`useQuery`/`useMutation`).
   - Example: `apps/web_app/src/modules/teacher/pages/TeacherLessonPlansPage.tsx` calls `apiClient.get('/v1/academic/teacher/lesson-plans')` inside manual `useEffect`/`useState`, bypassing RTK Query cache invalidation.
3. **Zustand Stores (`apps/web_app/src/store/*.store.ts`)**:
   - 6 stores (`app.store.ts`, `auth.store.ts`, `dashboard.store.ts`, `navigation.store.ts`, `profile.store.ts`, `settings.store.ts`), e.g. `DataTableFramework.tsx` reads `useSettingsStore()`.
4. **Browser Direct Supabase Client (`@supabase/supabase-js` in `package.json`)**:
   - Present in dependencies; must NOT be used to bypass backend Express RBAC APIs.

## 5. Architectural Reusability & Zero-Duplication Rules for Phase 2

1. **Follow `academic-management` Pattern**: Every new Stage 3 backend module must replicate `academic-management/`'s clean split: `routes/` → `controllers/` → `validators/` & `dto/` → `services/` (writes/transactions) & `queries/` (complex aggregations) → `repositories/` → `policies/` (`AcademicPolicy` / `ParentPortalPolicy` extensions).
2. **Enforce RTK Query (`apiSlice.ts`)**: All new web Stage 3 API hooks must inject into `apps/web_app/src/app/store/apiSlice.ts` rather than introducing new raw `apiClient` + `useEffect` fetches.
3. **Reuse Existing Infrastructure Before Building New**:
   - Upload & magic-byte validation → extend `apps/backend/src/middlewares/upload.middleware.ts`.
   - Object storage & signed URLs → reuse `apps/backend/src/services/storage.service.ts`.
   - Realtime push updates → extend `apps/backend/src/modules/notifications/realtime/notification.realtime.ts`.
   - LLM client wrapper → reuse/refactor `apps/backend/src/modules/academic-management/services/ai-provider.client.ts` into shared `src/lib/` or `src/services/ai/`.
   - Data tables, approval queues, charts, calendars, print/export → reuse `apps/web_app/src/modules/common/` (`ApprovalInbox`, `EnterpriseDataGrid`, `ChartBuilder`, `ReportViewer`, `EnterpriseCalendar`) and `DataTableFramework`.
