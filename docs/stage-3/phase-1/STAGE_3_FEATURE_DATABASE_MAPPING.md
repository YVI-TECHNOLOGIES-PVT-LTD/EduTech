# EduTrack ERP — Stage 3 Feature-to-Database Mapping & Blocker Analysis

> **Phase:** Stage 3, Phase 1 — Read-Only Database Mapping  
> **Database Contract:** `apps/backend/prisma/schema.prisma` (FROZEN — 148 PG tables, 7 views, 92 enums)  
> **Rule:** Every implemented workflow must map strictly to verified PG tables, columns, enums, constraints, views, triggers, and stored procedures. Missing schema structures are classified as **DATABASE BLOCKERS**.

| :--------------------------------------------------------------------------------------------------- | :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bulk session generation from timetable                                                               | **FULLY SUPPORTED**     | `classroom_sessions` + PG proc `s31_generate_classroom_sessions_for_date_range`                                                         | Reads `timetable_versions`/`timetable_entries`, skips `academic_calendar_entries` holidays/closures; idempotent via partial UQ `uq_classroom_sessions_timetable_date`. |

| Feature / User Story                                   | Support Status          | Target Table(s) / PG Objects                                                                             | Key Constraints & Operational Notes                                                                                                                                                                                                                                                           |
| :----------------------------------------------------- | :---------------------- | :------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Create & publish Homework brief + due date             | **PARTIALLY SUPPORTED** | `learning_activities` (`activity_type = 'homework'`, `instructions`, `due_at`, `activity_status`)        | Students/Parents can track deadlines, **but digital submissions, uploaded files, and digital reviews are BLOCKED on `'homework'` by DB triggers**.                                                                                                                                            |
| Create & publish Project + digital student submissions | **FULLY SUPPORTED**     | `learning_activities` (`activity_type = 'project'`), `learning_activity_submissions`                     | Multi-attempt `(activity_id, student_id, attempt_number)`; append-only immutable (`s32_prevent_submission_mutation`); requires text or files (`s32_deferred_check_submission_content`).                                                                                                       |
| Student project file uploads (PDF / Images)            | **PARTIALLY SUPPORTED** | `learning_activity_submission_files`                                                                     | Trigger `s32_validate_submission_file` caps at **5 files/attempt** & `'project'` only; `ck_s32_file_size` caps `1..10485760` bytes (10MB). Express `upload.middleware.ts` restricts MIME strictly to `PDF`, `JPEG`, `PNG`, `WEBP`.                                                            |
| Teacher project review, marks & resubmission request   | **FULLY SUPPORTED**     | `learning_activity_submission_reviews`                                                                   | `'project'` only (`s32_validate_review`); decisions `reviewed                                                                                                                                                                                                                                 | resubmission_requested`; immutable once created (`s32_prevent_review_mutation`). |
| Automatic overdue closure                              | **FULLY SUPPORTED**     | PG proc `s32_close_due_activities()`                                                                     | Scheduled job / service invocation sets `closed_at` & `closure_reason`.                                                                                                                                                                                                                       |
| Digital Homework submissions / grading                 | **DATABASE BLOCKER**    | _(Blocked by triggers `s32_validate_submission`, `s32_validate_submission_file`, `s32_validate_review`)_ | Only `'project'` accepts digital turn-in under current frozen DB.                                                                                                                                                                                                                             |
| Interactive activities & video/audio/code submissions  | **DATABASE BLOCKER**    | _(Orphan enum `assignment_type` is unused; MIME blocked)_                                                | `written_response`, `video_presentation`, `audio_submission`, `quiz` (inside S3.2), `draw_and_answer`, `match_pairs`, `fill_in_blanks`, `reading_assessment`, `public_speaking`, `code_simulator` have **no column/tables**, and `mp4`/`mp3`/`webm`/`docx` are rejected by upload middleware. |
