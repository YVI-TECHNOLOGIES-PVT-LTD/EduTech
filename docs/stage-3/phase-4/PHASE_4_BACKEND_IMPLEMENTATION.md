# Stage 3, Phase 4 — Backend Implementation

## 1. Module Layout (`apps/backend/src/modules/learning-activities/`)

- `learning-activities.types.ts` — Domain DTOs, S3.2 status/type unions, WebSocket event names, custom HTTP error hierarchy (`400`/`403`/`404`/`409`/`503`).
- `learning-activities.validation.ts` — Zod schemas validating timestamps (`due_at > assigned_at`, `late_submission_authorized_until > due_at`), numerical grading bounds, review decisions (`resubmission_allowed_until` required in future), and UUID params.
- `learning-activities.policy.ts` — Role and tenant extraction guards (`requireTeacherRole`, `requireStudentRole`, `requireAdminRole`, `ParentPortalPolicy.requireParentRole()`).
- `learning-activities.repository.ts` — 100% SQL-injection-safe `Prisma.sql` tagged templates inside `$transaction` (zero `$queryRawUnsafe` / `$executeRawUnsafe`). Joins `academic_years.org_id` correctly for tenant isolation (`sections` has no `org_id`).
- `learning-activities.service.ts` — Activity lifecycle, atomic project submission + file persistence before deferred trigger check, storage cleanup on failure, teacher evaluation, and non-blocking WebSocket + bulk DB notification dispatch.
- `learning-activities.controller.ts` & `learning-activities.routes.ts` — Mounted in `apps/backend/src/routes.ts` at `/v1/learning-activities` and `/learning-activities`.

## 2. Role-Scoped API Contract (`/api/v1/learning-activities`)

| Role Scope                                   | Endpoints                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| :------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Teacher** (`/teacher/*`)                   | `GET /overview`, `GET /assignments`, `GET /activities`, `POST /activities`, `POST /activities/close-due`, `GET /activities/:activityId`, `PATCH /activities/:activityId`, `POST /activities/:activityId/publish`, `POST /activities/:activityId/close`, `POST /activities/:activityId/extend-late`, `GET /activities/:activityId/audit`, `GET /submissions`, `POST /submissions/:submissionId/start-review`, `POST /submissions/:submissionId/reviews`, `GET /files/:fileId/download` |

| **Parent** (`/parent/*`, strictly read-only) | `GET /children/:childId/overview`, `GET /children/:childId/activities`, `GET /children/:childId/activities/:activityId`, `GET /children/:childId/files/:fileId/download`                                                                                                                                                                                                                                                                                                              |
| **Admin** (`/admin/*`)                       | `GET /overview`, `GET /filters`, `GET /activities`, `GET /activities/:activityId`, `POST /activities/close-due`, `GET /files/:fileId/download`                                                                                                                                                                                                                                                                                                                                        |
