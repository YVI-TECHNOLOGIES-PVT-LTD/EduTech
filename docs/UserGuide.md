# EduTrack ERP Stage-1 Admin Portal User Guide

## Overview

Welcome to the **EduTrack ERP Stage-1 Admin Portal**. This portal allows school administrators, admission officers, counsellors, and finance staff to manage daily educational operations and student intake workflows.

---

## Key Operating Workflows

### 1. Inbound Inquiry to Lead Conversion (`CRM ➔ Leads`)

1. Navigate to **CRM & Leads** from the sidebar.
2. Click **Capture New Lead Inquiry**.
3. Fill in student name, parent contact info, target grade, and source.
4. Review the auto-calculated **AI Lead Conversion Score**.

### 2. Campus Visit Scheduling (`CRM ➔ Campus Visits`)

1. Click the **Campus Visits Schedule** tab.
2. Click **Schedule Campus Visit** and select the prospective lead.
3. Assign a counsellor and set date/time.

### 3. Application Processing & Document Review (`Admissions ➔ Applications / Documents`)

1. Open **Admissions Pipeline** from the sidebar.
2. Select an application to view submitted documents.
3. Verify birth certificates, transcripts, and transfer certificates.

### 4. Entrance Assessment & Interview Scoring (`Admissions ➔ Assessments`)

1. Click the **Assessments** tab.
2. Select applicant and enter entrance examination test scores.
3. Click **Record Assessment Score**.

### 5. Admission Decisioning & Fee Receipt (`Admissions ➔ Applications / Fees`)

1. Approve the admission application.
2. Switch to **Fee Payment** tab.
3. Select payment mode (Online, Cheque, NEFT/RTGS, Cash) and enter transaction reference.
4. Click **Process Fee Collection**.

### 6. Stage-1 Final Student Enrollment (`Students ➔ Stage-1 Enrollment`)

1. Open **Student & Parent Management**.
2. Select the **Stage-1 Enrollment Execution** tab.
3. Select the fee-paid application, assign grade and section, and click **Execute Stage-1 Student Enrollment**.
4. The student record is generated in the **Enrolled Student Directory**.
