# EduTrack Accessibility Standard

## Accessibility Checklist (Definition of Done)
1. **Semantic HTML**: Use semantic landmark tags (`main`, `nav`, `header`, `section`, `footer`).
2. **Keyboard Navigation**: All interactive elements (buttons, links, inputs) must be focusable and operable using standard Keyboard navigation (`Tab`, `Enter`, `Space`).
3. **Focus Visibility**: Focus states (`focus:ring-2 focus:outline-none`) must remain visible for keyboard users.
4. **ARIA Attributes**: Use explicit `aria-label`, `aria-expanded`, and `aria-hidden` attributes for icon buttons and dynamic UI controls.
5. **Form Labels**: Every input element must be explicitly associated with a `<label>` or `aria-label`.
