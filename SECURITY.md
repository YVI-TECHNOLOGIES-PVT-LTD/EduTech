# Security Policy & Vulnerability Disclosure

## Supported Versions

| Version | Supported |
| :------ | :-------- |
| `1.0.x` | Yes       |
| `< 1.0` | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within EduTrack, please report it confidentially rather than filing a public issue.

- **Security Email:** security@edutrack.io
- **Response Time:** We will acknowledge receipt within 24 hours and provide a detailed patch timeline within 72 hours.
