# Changelog

All notable changes to the EduTrack Enterprise Platform are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-04

### Added

- **Monorepo Stabilization:** Standardized `pnpm` workspace linking and `Turborepo` pipelines across all 7 workspace packages.
- **ESLint & TypeScript Architecture:** Restored `@edutrack/config` governance with clean typechecks across Node, React, and React Native targets.
- **Backend Dual-Write Engine:** Added atomic dual-write compatibility layer for legacy attendance tracking.
- **Enterprise Documentation Suite:** Comprehensive architectural documentation, C4 diagrams, ADRs, and developer guides.
