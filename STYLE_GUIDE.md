# Code & Style Guidelines

## 1. Naming Conventions

- **Folders & Files:** `kebab-case` for utils, modules, and config files (`student-details.tsx`, `auth-service.ts`).
- **React Components:** `PascalCase` for React component files and exports (`StudentProfileCard.tsx`).
- **Interfaces & Types:** `PascalCase` (`UserSession`, `AdmissionStatus`).
- **Constants:** `UPPER_SNAKE_CASE` (`MAX_BATCH_SIZE`, `DEFAULT_ACADEMIC_YEAR`).

## 2. Formatting Rules

- **Indentation:** 2 spaces.
- **Quotes:** Single quotes `'`.
- **Semicolons:** Always required.
- **Line Width:** 100 characters max.
