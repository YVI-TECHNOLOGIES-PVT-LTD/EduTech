EduLyfe brand kit (logo concept 4B: EL monogram with life leaf)
Tagline: LONG LIVE EDUCATION

All files are PNG with transparent backgrounds unless noted.
Colour variants:
  color       full colour, for white or light backgrounds
  reversed    for navy or dark backgrounds
  mono-black  one colour, for black-and-white print, stamps or fax
  mono-white  one colour, for photos or coloured backgrounds

Folders
  01_Logo_Horizontal            symbol + name + tagline, side by side (widths 500-4000 px)
  02_Logo_Horizontal_NoTagline  symbol + name, for headers and app bars
  03_Logo_Stacked               symbol above name + tagline, for square spaces
  04_Wordmark_Text              the name "EduLyfe" only
  05_Wordmark_Text_Tagline      name + tagline, text only
  06_App_Icon_Tile              rounded-square icon: color (navy), light (white), amber; 16-2048 px
                                (16/32/48 favicon, 180 Apple touch, 192/512 web app)
  07_Symbol                     the monogram alone, no tile (heights 64-2048 px)
  08_Android
    res/                        copy into app/src/main/res/ of the Android project
      mipmap-*/ic_launcher.png             legacy launcher icon (48dp)
      mipmap-*/ic_launcher_round.png       round launcher icon (48dp)
      mipmap-*/ic_launcher_foreground.png  adaptive icon foreground (108dp)
      mipmap-*/ic_launcher_background.png  adaptive icon background (108dp, navy)
      mipmap-*/ic_launcher_monochrome.png  Android 13+ themed icon layer
      mipmap-anydpi-v26/                   adaptive icon XML wiring the layers together
      drawable-*/ic_stat_edulyfe.png       notification icon (24dp, white)
      drawable-*/splash_icon.png           Android 12+ splash screen icon (240dp)
    play_store/                 512x512 store icon, 1024x500 feature graphic

Colours
  Navy   #12305E   primary
  Amber  #F5A623   accent (use #B86E00 for amber text on white)
  Leaf   #3CC274   life leaf
  Slate  #4A5A73   tagline on white
Font: Plus Jakarta Sans (ExtraBold for the name, SemiBold for the tagline), SIL Open Font License.
